Common Blur Login Problems
==========================

Sometimes users encounter login issues. Fortunately, many are easy to fix.

Incorrect Password
------------------

An incorrect password is the most common login issue.

Check for:

* Typing mistakes
* Caps Lock enabled
* Incorrect keyboard layout
* Extra spaces

Re-enter your password carefully.

Incorrect Email Address
-----------------------

Make sure you're using the same email address that was registered with your Blur account.

Internet Connection Issues
--------------------------

Poor connectivity can interrupt authentication.

Try:

* Restarting your router
* Connecting to another network
* Refreshing the page
* Restarting your device

Browser Problems
----------------

If you're using the web version:

* Clear browser cache.
* Delete cookies.
* Disable unnecessary extensions.
* Update your browser.
* Try another supported browser.

Server Maintenance
------------------

Temporary maintenance may occasionally affect login services.

If everything appears correct on your side, wait a short time before trying again.
